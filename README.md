# WG-Organisationsapp

Eine Android-App zur Organisation des WG-Alltags, einschließlich Aufgabenverwaltung,To-Do-Listen, Haushaltsbuch und mehr. Entwickelt als Gruppenprojekt mit Android Studio in Kotlin.

## Technologien
- Kotlin
- Android Studio
- Git / GitHub

## Funktionen
- Aufgabenverwaltung
- To-Do-Liste
- Haushaltsbuch
- Einkaufsliste
- WG-Organisation

## Meine Beiträge
Mein Hauptbeitrag lag in der Entwicklung der To-Do-Listen-Funktion, einschließlich:

- Implementierung der To-Do-Logik
- Entwicklung der UI-Komponenten
- Verarbeitung von Benutzerinteraktionen
- Bugfixes und Verbesserungen
- Integration in die bestehende App-Struktur
